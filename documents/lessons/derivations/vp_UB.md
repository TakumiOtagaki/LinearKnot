# VP の反対側に枝がある場合

固定対を丸括弧、追加対を角括弧で示す。同じ種類の開き括弧と閉じ括弧を、内側から順に対応させて読む。入力で決まっている固定対は、結合時に再び選び直さない。

```text
配列　　GGAGAAACAAACGAAACC
固定対　(......)..........
追加対　.[.[.......][...]]
完成形　([.[...)...][...]]
```

## 配列上で対の両端を見る

![18塩基、上の固定対は1本、下の追加対は3本。](vp_UB-structure.png)

上の青い弧は固定対 $G$、下の紫の弧は追加対 $G^\prime$ を表す。端の順が交互なら2対は交差する。

- 固定対　(1,8)
- 追加対　(2,18)、(4,12)、(13,17)

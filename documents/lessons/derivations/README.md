# 座標と規則名から読める導出木の図譜

図は保存した具体的な導出の全ノードを示す。親から下向きの矢印を一段たどると、一回の規則適用で選ばれた子が分かる。一つの木の局所重みを掛け合わせるとその導出の重みになる。分配関数を求めるときは、文法が許すすべての導出についてそれらを足す。

頂点には状態・座標・規則名を表示した。BE のセミコロンで区切った二対は外側と内側の固定対。表の子の番号は図の各頂点に対応する。座標は左端を 1 とし、区間の両端を含む。

図の元データは論文用教科書に保存された実行記録（実装版 58a2b796）。以下はその記録から親子と規則を復元したもので、図には各状態で選ばれた規則を一つずつ描いた。根が W の図は全配列の導出で、根が WI や WIP の図は、その状態から下の部分木を示す。

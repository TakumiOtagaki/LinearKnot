# 最初に一枚で読む用語・記号

本教材の $\alpha$（inside）と $\beta$（outside）は実数の重みで表す。教科書の擬似コードに出る対数表との換算は[教科書と記号の対応](textbook-guide.md#実数の重みと教科書の-log-表)に示す。

**塩基から構造まで。** RNA（リボ核酸）は、A・C・G・U の四種類の塩基をもつ単位が鎖状に並んだ分子である。配列はこの並びを左から文字で書いたもの。位置を 1 から数え、二つの位置が組になるとき、その組を塩基対 $(i,j)$ と書く。未対合は相手を持たないこと。鎖の上に塩基対を弧で描き、端が交互に並べば交差、片方がもう一方の内に収まれば入れ子である。構造とは、この教材では完成した塩基対の一覧を指す。足場（scaffold、記号 $G$）はそのうち必ず残す、あらかじめ与えた互いに交差しない対である。例えば $G=\{(2,8)\}$ なら、位置 2 と 8 は他の位置と組めない。

**条件、重み、確率。** 足場を与えた条件付きの確率とは、その配列と足場で許した構造だけで割合を取ること。重みは各候補の選ばれやすさを比較する非負の数。たとえば二通りの重みが 2 と 3 なら、分配関数（重みの合計）$Z=5$、確率は $2/5$ と $3/5$ である。合計で割り、確率の総和を 1 にすることを正規化という。集団全体について、各場合に「値×その場合の確率」を計算して足した数を期待値、または平均と呼ぶ。塩基対確率（BPP）は、指定した対を含む場合の確率の合計である。

**エネルギーから重みへ。** $E$ は構造に与えたエネルギー、$T$ は絶対温度（ケルビンで測る温度）、$R$ はエネルギーと温度の単位をそろえる気体定数。$\exp(a)$ は約 2.718 を底とする指数関数で、$\exp(a+b)=\exp(a)\exp(b)$ を満たす。ボルツマン重み $\exp(-E/(RT))$ は、温度を固定するとエネルギーが低いほど大きい。積になる性質のおかげで、小部分のエネルギーを足すことが、小部分の重みを掛けることに対応する。$\log$ はこの指数関数の逆の計算である。

**文法を計算する。** 規則は「ある部分をどんな部品で組めるか」を指定する。状態（項目）は部品の種類と位置を指定した部分問題。たとえば $V(2,8)$ は位置 2 と 8 の対で閉じた部分を扱う。親は作りたい部品、子はその材料、根は配列全体の状態である。親で規則を一つ選び、そのすべての子でも同じことを繰り返して出来上がる一本の木を導出と呼ぶ。規則を一回使うときだけ掛ける重みが局所重みである。

**順に値を作り、逆にたどる。** $\alpha(v)$ は状態 $v$ を作る導出の重みの合計（inside）。forward は材料から結果へ値を送る計算。$\beta(v)$ は $\alpha(v)$ をほんの少し変えたときの結果 $Z$ の変化率（outside）。backward は先ほどの計算を出力から材料へ戻り、各材料の変化が最終結果へ届く倍率を求める計算である。BE は二つの固定対を指定し、その間の左右の腕を扱う状態。BE にとっての「外側」は、その値を使った残りの組み立てを意味する。二本の腕の間にある位置も、その残りの組み立てに登場できる。

|式で見る印|この教材での読み方|小さい例|
|---|---|---|
|$[i,j]$|両端を含めた連続した位置|$[2,4]$ は 2, 3, 4|
|$\{a,b\}$、$\cup$|要素の集合、二つの集合に属するものを合わせる操作|$\{1,2\}\cup\{4\}=\{1,2,4\}$|
|$\sum$、$\prod$|指定した値をすべて足す、またはすべて掛ける|2 と 3 の和は 5、積は 6|
|$\partial Z/\partial x$|ほかの独立な入力を固定し、$x$ の小さな変化に対する $Z$ の変化率を取る|$Z=4x+6$ なら 4|
|$\bar x$|出力を決めておき、$x$ を変えたときのその出力の変化率を略記する|出力が $Z$ なら $\bar x=\partial Z/\partial x$|
|$\mathrel{+}=$|既にある値へ足し込む|3 に 5 を足し込むと 8|
